Repository: github.com/wre9-tesh/ML_Landfill_Detection. The grader's manual gives a quick check and the full path; the replication manual gives every command with its expected output.

Setup

Python 3.13 on Windows PowerShell (the scripts also run on Linux and macOS):

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

The package versions used for training are pinned in requirements.txt (scikit-learn 1.9.1).

Run order

Steps marked EE need a free Google Earth Engine account and project. Every other step runs from files in the repository.

#CommandWrites
1python scripts/build_samples.pydata/samples/points.csv
2python scripts/build_background_v2.pydata/samples/points_v2_background.csv
3 (EE)python scripts/gee_features.py --project ID, and again with --points data/samples/points_v2_background.csv --out data/features_v2The 12 base features
4 (EE)The same two fetches with --stack extra and --out data/features_v3/main or data/features_v3/backgroundThe 10 extra features
5python scripts/run_models.py --features data/features/features.csv data/features_v2/features.csv --extra data/features_v3/main/features.csv data/features_v3/background/features.csv --rule best --out data/results_v3Validation results (about 20 minutes on four cores)
6python scripts/freeze_model.py --results data/results_v3The frozen model
7 (EE)python scripts/gee_export_gujarat.py --project ID --boxes labels/gujarat_boxes.json, and again with --stack extraFeature rasters for data/gujarat/ and data/gujarat_x/
8python scripts/score_gujarat.py --version 3data/gujarat_results_v3/
9python scripts/diagnostics.py, python scripts/alarm_diagnostics.pydata/analysis/
10python scripts/build_site_data.pyThis site, in docs/

Steps 1, 2, 5, 6 and the first command of step 9 were rerun from a clean clone and reproduce the committed files byte for byte. Step 10 can be run with --check, which writes nothing and fails if any page or data file of this site differs from what the result files give.

Data access

  • In the repository: all labels and outlines, all sample points, all four feature tables, all validation and Gujarat results, and the model score of every scored pixel (data/gujarat_results_v3/scores/).
  • Not in the repository: the Gujarat feature rasters, several gigabytes. Step 7 rebuilds them from public data. The image chips on this site were cut from them with scripts/make_chips.py.
  • No account needed: steps 1, 2, 5, 6, 9 (first command) and 10.
  • No private data: the repository holds no credentials or keys. An Earth Engine project identifier is passed on the command line and is not stored.

Verifying the freeze

The order of events can be checked in the history:

git log -1 --format="%h %ad %s" 8711855       # the test list is sealed
git log -1 --format="%h %ad %s" freeze-v3     # the model and rules are frozen
git log --format="%h %ad %s" -- data/gujarat_results_v3/summary.json   # Gujarat is scored

The earlier tags freeze-v1 and freeze-v2 mark the two earlier versions in the same way.

AI-use disclosure

An AI assistant, Claude (Anthropic), was used throughout this project through Claude Code.

  • What the assistant did: wrote the Python scripts in scripts/ to the author's requirements; ran model training, the diagnostics and the reproducibility checks; searched for and summarised related papers; drafted the documentation, the three PDF guides and this website, including its charts and interactive elements; proposed parts of the study design, such as the freeze procedure and the diagnostic analyses, which the author accepted, changed or rejected.
  • What the author did: chose the question; screened every OpenStreetMap candidate and drew every training outline; compiled and outlined the Gujarat test list; ran every Earth Engine fetch and export and the Gujarat scoring on their own machine; judged all 100 alarms in the hand check; made every decision about labels, features, versions and what to report.
  • No label or verdict was produced by AI. The assistant never saw the high-resolution imagery used for labelling and for the hand check.
  • How AI output was checked: results were reproduced from a clean clone; every number on this site is filled from the result files by a script, not typed; the author read the pages against the result files.
